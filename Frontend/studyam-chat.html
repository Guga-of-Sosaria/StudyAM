Olá, João! Vou te explicar como resolver equações do 2º grau passo a passo. 😊

Uma equação do 2º grau tem a forma ax² + bx + c = 0, onde a ≠ 0. Para resolver, usamos a Fórmula de Bhaskara:
Fórmula de Bhaskara
x = (-b ± √Δ) / 2a
onde Δ = b² - 4ac
Exemplo: Para x² - 5x + 6 = 0 (a=1, b=-5, c=6):
Δ = 25 - 24 = 1
x₁ = (5 + 1) / 2 = 3
x₂ = (5 - 1) / 2 = 2

StudyBot IA
Ótima pergunta! Quando Δ < 0, a equação não possui raízes reais.

Isso significa que o gráfico da parábola não toca o eixo X. Existem três casos:

• Δ > 0 → Duas raízes reais distintas ✅
• Δ = 0 → Uma raiz real (raiz dupla) ✅
• Δ < 0 → Nenhuma raiz real ❌ (no conjunto dos Reais)
